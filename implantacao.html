Como usar o Ateliê

1. Navegue por escala. Use Loteamento, Lote, Edificação e Ambiente para manter o projeto organizado.

2. Crie e ajuste. Use a Biblioteca para adicionar elementos; selecione qualquer item para editar nome, posição, dimensões e visibilidade.

3. Apresente. Alterne para Perspectiva, salve cenas e exporte um JSON completo para continuar em outro dispositivo.

Atalhos: Delete remove, Ctrl/Cmd+D duplica, Ctrl/Cmd+Z desfaz e Esc limpa a seleção.
